network. Reconcile the network's TWO records-of-record against LIVE reality and
report only real DRIFT. You have read-only tools; you never change anything.

RECORDS OF RECORD (what the network SHOULD be):
1. NetBox (netbox tools) — IPAM / DCIM: sites, devices, VLANs, prefixes, IP

LIVE REALITY (what the network ACTUALLY is):

  clients, gateway/switch state.

TASK:
- Compare each record against live Omada reality. DRIFT is anything present in

- If you CANNOT read a record (e.g. the github token lacks access to the private

- Keep it high-signal: at most the 8 most-actionable drifts, most-important first.
